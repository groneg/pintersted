# CLAUDE.md

This file gives guidance to Claude Code when it works in this repository.

## About this repository

pintersted explores parallels between the teachings of Jesus and quantum
mechanics ("quantum Christ Consciousness"). Content includes dialogues,
essays, and source-text references from the Bible, 1 Enoch, the Dead Sea
Scrolls, and other ancient books.

## Writing style

Write all prose in this repository in plain speak, like Google reference
docs. Follow the principles of ASD-STE100 (Simplified Technical English).

### ASD-STE100 rules

- Keep sentences short. Use a maximum of 20 words in an instruction. Use a
  maximum of 25 words in a description.
- Give one instruction in each sentence.
- Use the active voice. Write "the observer collapses the wave function,"
  not "the wave function is collapsed by the observer."
- Use one word for one meaning. Do not switch between synonyms for the
  same idea.
- Use simple verb tenses (past, present, future). Do not use perfect or
  progressive tenses when a simple tense works.
- Use the articles "the," "a," and "an." Do not drop them.
- Do not put more than three nouns in a row.
- Put warnings and conditions at the start of the sentence.

### Plain-speak rules (Google reference doc style)

- Lead with the point. Put the most important sentence first.
- Speak to the reader as "you."
- Use common words. Write "use," not "utilize." Write "help," not
  "facilitate."
- Define a term the first time you use it. Example: "superposition (a
  state that mixes two or more states at the same time)."
- Use numbered lists for steps. Use bullet lists for facts.
- Keep paragraphs to four sentences or fewer.
- Use headings that say what the section does, not clever titles.

### Source-quotation rules

- Quote ancient texts exactly. Do not paraphrase inside quotation marks.
- Cite the book, chapter, and verse. Name the translation. Example:
  John 8:12 (KJV), 1 Enoch 43:2 (Charles), 1QS 3:15 (Vermes).
- Name the collection a text comes from. Do not put a text in the wrong
  collection. Example: the Gospel of Thomas is from Nag Hammadi, not from
  the Dead Sea Scrolls.
- Mark interpretation as interpretation. When prose draws a parallel
  between scripture and physics, say that the parallel is a metaphor, not
  a scientific claim.
